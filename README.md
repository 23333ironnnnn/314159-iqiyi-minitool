# 爱奇艺互动小应用打包工具

把已经构建好的网页游戏打成供爱奇艺号上传的 ZIP。需要 Python 3.9 或更高版本，仅使用标准库。项目为创作者社区维护。

## 一条命令试用

下载源码，在解压后的文件夹打开终端，运行：

~~~sh
python3 pack.py
~~~

当前目录将出现 iqiyi-app.zip，内容是原创两分支测试短剧《末班车》。用自己的游戏时，先按游戏原有方式构建，然后把包含 index.html 的目录传给脚本：

~~~sh
python3 pack.py "/path/to/game/dist" -o "/path/to/release/game-v1.zip"
~~~

同一份输入可重复运行。输入有变化且输出文件已存在时，请指定新文件名。只向平台上传生成的游戏 ZIP。每款游戏的封面在投稿后台单独确认。

## 官方规范与广告测试包

在发布后台点「校验小应用 → 复制指令」，按当期链接下载并解压官方开发资料。本次指令中的压缩包名为 interactive-app-guide1.1.zip，本地解压的 SKILL.md 自报版本为 1.2.0。先读 SKILL.md，再读对应能力的 references；激励广告用 references/ad.md。已有项目保留原有玩法。新项目可参考官方框架中的 HTML、CSS、JS 和资源目录。[开发规范 ZIP](https://static-s.iqiyi.com/lequ/20261116/interactive-app-guide1.1.zip) · [框架模板 ZIP](https://static-d.iqiyi.com/lequ/20260910/interactive-app.zip)

如要测试激励广告，使用独立示例《车票背面》：

~~~sh
python3 pack.py example-ad -o iqiyi-reward-test.zip
~~~

在爱奇艺 App 的已授权沙箱主页面打开，点击「看广告，读车票背面的留言」。示例加载平台指定的 JSSDK，通过 `window.iqiyi.nativeCallback("Ad", "showRewardAdByH5Game", {}, callback)` 请求广告。一次只请求一条广告。回调只读取第一个参数的 code，成功后这次打开页面只解锁一次。

| 回调 code | 页面行为 |
| --- | --- |
| 1001 | 解锁留言 |
| 1002 | 已拉起但未获得激励，保留重试 |
| 1003 | 加载失败，保留重试 |
| exception 或未知结果 | 提示暂不可用，留言保持锁定 |

电脑端可检查基本排版。真机分别测试完整观看、中途关闭、广告加载失败时的重试和快速连点；最终曝光及收益以创作者后台为准。SDK 未加载时仍能读正文。[广告接入规范](https://pages.iqiyi.com/up/interactive-app.html#s3-4)

## 交给 AI

> 读这个工具的 README。把「游戏项目路径」适配成爱奇艺号的纯前端互动小应用。保留本作视觉、存档和玩法，将素材本地化，移除其他平台的专用入口和外部跳转。用项目已有命令构建，在手机竖屏测试首屏、完整一局和再玩。用 pack.py 生成 ZIP，给我路径、字节数和实测结果，另按下方发布表单给出可复制的名称和一句话简介、分类建议、作者封面待办及是否参赛。先按普通投稿、无广告处理。按本次「复制指令」读取官方规范及所需 reference；指定广告时对照 references/ad.md 和本仓库 example-ad，指定参赛时核对当期活动条件。

## 本地检查的范围

脚本检查根入口、ZIP 完整性及大小。平台要求上限 20 MB，本工具按 20,000,000 字节计算。它检查常见 HTML、CSS 资源引用和部分 JavaScript 字面量，提示缺失文件、外部或根路径。为防整库误传，脚本会拦截开发配置、Markdown、密钥文件等常见杂项。此为工具的打包约定。

动态请求、srcset、脚本拼接地址、宿主广告接口和完整交互须结合项目检查。普通玩法和素材须可离线运行。端内能力可通过 HTML script 的 src 引入指定的 https://static-d.iqiyi.com/webplatform/jssdk/iqiyi.js。检查业务外链和手机竖屏触控，再进创作者后台做平台校验和预览。

## 第一次投稿

1. 在电脑上打开爱奇艺号，用爱奇艺账号登录。首次使用按页面引导完成账号资料和实名认证。[爱奇艺号](https://creator.iqiyi.com/)
2. 选「发布作品 → 互动小应用 → 去发布」。部分界面从「新的创作」进入。已有离线游戏可直接走发布入口。群公告已说明全量开放；若看不到入口，再联系运营核实。
3. 在「校验小应用」点「复制指令」，交给 AI 按当期指令核对构建产物。上传游戏 ZIP，在右侧预览里实际玩一遍，再填写下表。测试时可选「保存草稿」。
4. 准备正式提交时点「发布小应用」。在「内容管理 → 互动小应用」查审核状态。退回时看「详情」。首版上线后可发新版本；新版通过审核后替换旧版。

### 对照发布页填写

| 后台字段 | 要求 | 《末班车》示例 |
| --- | --- | --- |
| 应用名称 | 必填，最多 30 字，以页面计数为准 | 末班车 |
| 应用简介 | 选填，最多 20 字 | 一把遗落的钥匙，两个结局 |
| 应用分类 | 必填，从后台分类列表选择 | 按剧情互动玩法匹配实际选项 |
| 应用封面 | 必填，由作者为本款作品定稿，按封面旁的信息提示核对规格 | 待作者选择 |
| 参与活动 | 参赛时选对应活动 | 普通投稿留空 |

## 广告与参赛

- **激励广告**是可选接入。例：一局结束后，让玩家自行选择「看广告，再续一次」或「直接重玩」。在发布页「广告服务 → 查看接入规范」核对当前接口和回调，再按平台真实回调处理完整观看、取消、失败和重复回调。广告不可用时保留重玩。上传带广告的包后，作者按后台提示签署内容合作协议，并在爱奇艺 App 实测。分成比例、期限和结算以当期协议为准。[广告接入规范](https://pages.iqiyi.com/up/interactive-app.html#s3-4) · [开发者手册](https://pages.iqiyi.com/up/interactive-app.html) · [运营 FAQ](https://qcnk4nyi5lh9.feishu.cn/wiki/W87Mwbl3ziJeizkRXdacJ0T4nIc)
- **限时征集赛**仅在作者选择参加时勾选对应活动。2026 年本期截止 12 月 3 日 23:59；创意佳作奖与创作参与奖需累计上线至少四款原创作品。使用活动授权 IP 的作品限爱奇艺端内独家上线；使用前核对具体授权范围。长期多渠道发行更适合使用自有原创内容。规则核对日期为 2026-11-23。[活动规则](https://aic.iqiyi.com/activity/ai-contest-2026)
